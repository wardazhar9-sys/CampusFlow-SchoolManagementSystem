# CampusFlow — School Management System

A full-stack web application built to digitize daily school operations, featuring role-based portals for administrators and teachers, real-time analytics, fee tracking, and academic management.

## Key Features

### Admin Portal
- **Live Analytics Dashboard:** Real-time overview of total students, teachers, classes, and fee collections.
- **Academic & User Management:** Organized records and search functionality for Students, Teachers, and Classes.
- **Fee Management:** Supports recording and tracking both cash and online fee payments.
- **Examinations & Notices:** Manage exam results and publish school-wide announcements.

### Teacher Portal
- **Class Roster:** View assigned classes and enrolled student lists.
- **Homework & Assignments Diary:** Create and manage daily homework entries for students.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP (MySQLi)
- **Database:** MySQL
